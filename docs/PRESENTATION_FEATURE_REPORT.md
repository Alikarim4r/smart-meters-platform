## الشريحة 04 — البنية التقنية

```
Flutter Apps (Android / macOS / Windows / Web)
        │  HTTPS + JWT (anon key فقط — بدون service_role في العميل)
        ▼
Supabase
  ├── Auth (تسجيل / جلسة / بريد)
  ├── Postgres + Row Level Security
  ├── Storage (صور القراءات + شعارات التقارير)
  └── RPCs إدارية (موافقة مستخدم، تصحيح قراءة، …)

Entry فقط: قائمة انتظار محلية (SQLite) للمزامنة عند عودة الشبكة
```

**حزمة مشتركة:** `packages/smart_meters_core`  
Auth · النماذج · المستودعات · الثيم · بوابة الموافقة · الصلاحيات

**[سكرين شوت 03 — اختياري: هيكل المجلدات في Cursor/Finder]**  
- يظهر `apps/` و `packages/` و `supabase/`  
- مفيد لجمهور تقني فقط؛ يمكن حذفه للجمهور التنفيذي

## الشريحة 05 — الهيكل التنظيمي للبيانات

```
الجهة (Organization)
  └── المنطقة (Zone)  ← شعار تقارير اختياري
        └── الموقع (Site)  ← شعار تقارير اختياري
              ├── العدادات (Meters) حسب الفئة/المصدر/الوحدة
              ├── القراءات (Readings) + صور
              ├── مجموعات COP
              └── شبكة المياه (مخطط عقد واتصالات)
```

**فئات العدادات (قابلة للتوسيع من الأدمن):**
- مياه (ماء عذب، TSE، RO، تانكر، ري، …)
- كهرباء (شبكة، مولد، شمسي، UPS، …)
- BTU / تبريد
- وقود / ديزل

**مفاهيم مهمة للبرزنتيشن:**
- عداد رئيسي / فرعي
- عداد فعلي (قراءة مباشرة) مقابل افتراضي (محسوب)
- تطبيع الوحدات: `قيمة × معامل الوحدة × مضاعف العداد`

*(شريحة مخطط فقط — بدون سكرين شوت، أو استخدم سكرين الهيكل من الأدمن كخلفية خفيفة)*

**[سكرين شوت 04 — تبويب الهيكل في الأدمن]**  
- **المصدر:** Admin → Structure  
- **المحتوى:** شجرة/قائمة جهات → مناطق → مواقع  
- **موضع:** يمين أو يسار المخطط

## الشريحة 06 — الأدوار والصلاحيات

| الدور | الأدمن | الإدخال | العرض | ملاحظات |
|-------|:------:|:------:|:-----:|---------|
| مالك المنصة / Super Admin | ✓ | ✓ | ✓ | إدارة شاملة |
| مسؤول موقع (Site Admin) | ✓* | ✓ | ✓ | *ضمن مواقعه |
| فني (Technician) | — | ✓ | ✓ | يحتاج موافقة + مواقع |
| عارض (Viewer) | — | — | ✓ | يحتاج موافقة + مواقع |
| طلب فني (عند التسجيل) | — | — | — | معلق حتى الموافقة |

**قاعدة ذهبية للعرض:**  
الموافقة وحدها لا تكفي — يجب تعيين **موقع واحد على الأقل** لفتح الإدخال/العرض.

**[سكرين شوت 05 — حوار الموافقة مع اختيار الدور والمواقع]**  
- **المصدر:** Admin → Users → موافقة مستخدم معلّق  
- **المحتوى:** الدور + قائمة المواقع معلّمة + تنبيه «إلزامي اختيار موقع»  
- **موضع:** أسفل الجدول أو شريحة فرعية
